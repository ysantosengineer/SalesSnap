# Technology stack

Frontend: Next.js, React, TypeScript, App Router, and Tailwind CSS. Backend: Python, FastAPI, Pydantic, SQLAlchemy, and Alembic. PostgreSQL is the database. Pandas supports data processing. Scikit-learn is the initial ML library; add others only with justification. OpenAI API provides generative AI.

Use pytest for backend tests and frontend ecosystem test tools only when needed. Ruff and ESLint enforce quality. Docker and Docker Compose provide local infrastructure; GitHub Actions provides CI/CD.

Do not add Redis, RabbitMQ, Kafka, Kubernetes, Celery, microservices, queues, or distributed caches prematurely.

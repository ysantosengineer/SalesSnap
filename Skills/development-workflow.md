# Development workflow

The official stage workflow is:

```text
1. Read Skills
2. Inspect repository
3. Read stage scope
4. Identify dependencies
5. Break work into small units
6. Define branches
7. Define expected commits
8. Implement first unit
9. Validate
10. Commit
11. Repeat
12. Run complete validation
13. Update documentation
14. Update Skills if architecture changed
15. Produce final stage report
```

Do not anticipate future-stage functionality. For example, a CSV-import stage must not implement forecasting, RFM, or OpenAI merely because they may later use imported data.

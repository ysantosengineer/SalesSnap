# Frontend standards

Use Next.js, TypeScript, React, App Router, and Tailwind CSS. Prefer typed interfaces, reusable components where they have a real use, and a simple centralized API-call layer. Provide loading and error states when needed. Code and names are English.

Avoid giant components and unused abstractions. The frontend must not perform analytical logic that belongs in the backend.

Use the semantic visual tokens, shared UI primitives, responsive application shell, interaction states, and accessibility rules defined in `design-system-standards.md`. Do not create isolated visual variants when an existing primitive can represent the behavior.

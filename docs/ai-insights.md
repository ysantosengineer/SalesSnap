# AI Insights

`Authenticated user → tenant-scoped analytics services → structured context → OpenAI → Pydantic validation → frontend`.

The provider is an interpretation layer. Dashboard, RFM, forecasting, anomalies, and stock-risk calculations remain deterministic. Context is bounded and contains no secrets. Imported names are wrapped as data and cannot alter instructions. Insights are generated on demand, require evidence, and are advisory only.

V1 has no AI Chat, memory, RAG, vector database, SQL generation, write action, insight persistence, causal inference, or automatic purchasing.

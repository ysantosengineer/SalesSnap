# SalesSnap

SalesSnap is a SaaS foundation for future sales intelligence: commercial-data analysis, dashboards, customer segmentation, demand forecasting, anomaly detection, inventory risk, and AI-generated insights.

## Stage 1

This repository currently provides only the technical foundation: a Next.js frontend, FastAPI backend, PostgreSQL local infrastructure, and a health integration. Product features are deliberately deferred.

## Planned stack

- Next.js, React, TypeScript, Tailwind CSS
- Python, FastAPI, Pydantic, SQLAlchemy, Alembic
- PostgreSQL, Docker Compose, GitHub Actions
- Pandas, Scikit-learn, and OpenAI API in later scoped stages
